# 《Judy 瑜伽疗愈》 - 章节 0 - 第 11 页

其實身體一有問題就會發出警訊提醒我們，但是大多被「我很忙」這個藉口忽略了，如果不能及時改善，一切都來不及了。

光是呼吸和拉開我駝了很久的背，我大概就上了1年，老實說，很多大家都知道的、美麗的、有如絢麗神話般的瑜伽動作我都不會，但是在最基礎的步驟裡學習，接通我小宇宙的經絡和能量，讓我在每一次大能量消耗的舞台劇演出之後，還能感覺精力充沛，歌舞劇的唱跳之後還保持精神奕奕。每一天你都會有「心」發現，每一天健康也會更好一點。

謝謝 Judy 老師，因為妳，我醒了。

（作者為音樂製作人、評審、電視節目主持人）
