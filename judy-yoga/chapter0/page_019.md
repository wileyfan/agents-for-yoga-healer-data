# 《Judy 瑜伽疗愈》 - 章节 0 - 第 19 页

輯地去抽絲剝繭，再深入淺出地介紹，如何融入瑜伽動作，並選擇適合自己的動作，透過身體的本身自癒力，不但預防再次受傷並且療癒自己。身體有病痛，除了就醫選擇適當的診斷與治療外，很重要的一點必須了解產生的原因以及該如何預防。了解原因之後，尋求適當的處理很重要，瑜伽的確是一門很值得推薦的方法。

臨床工作上，我常在看診時看見很多病人因為運動而受傷，其中因為瑜伽而受傷的也不在少數。但病人往往不知自己已經受傷或怎麼受傷的，而且仍然繼續練習。很多的原因不外乎追求較複雜的體位法、暖身不夠、對於瑜伽動作的不了解，或者本身有潛在的病痛但自己以及授課老師並不清楚。

由於很多瑜伽上課是一對多的授課方式，而非個別化的教學。因此，有時老師無法完全了解個別學生的狀況。同一種瑜伽動作也很難全體適用，很多的運動傷害也是如此而產生，因此運動的目的反而沒有達到。

本書透過很多的圖片，配合文字說明，提供讀者更深一層去認識瑜伽，讓大家自我審視是否有不足，如核心肌群太弱如何促進的方法；如筋膜放鬆加上瑜伽動作伸展、肌力強化及呼吸法的結合，是一種很適合生活緊繃、壓力過大的現代人，提升身心靈的運動。

（作者為泰合復健科診所院長）
