# 《Judy 瑜伽疗愈》 - 章节 3 - 第 3 页

如何練習療癒瑜伽？


## 第3章


瑜伽的練習能促進身體體液的循環，但首先要能保持良好的體液，要從喝對水開始。多喝鹼性水，例如檸檬水或不含咖啡因的天然果茶，都能讓身體保持活力。

刺激性飲料如咖啡、濃茶，每天1～2杯即可，不要過多，太多的刺激物會干擾身體的平衡，反而造成依賴性，喝久了容易愈喝愈上癮，就像藥物成癮一樣，不喝反而會心悸，很難戒。

食物的選擇應以當令、粗食為主，不挑食，才能維持食物中電解質的平衡。鈉離子、鉀離子等對維持血漿滲透壓，酸鹼平衡及神經肌肉興奮性有很重要的作用，一旦失去平衡，就會有病理性變化。

這也是為什麼人一生病，醫師就要看血液及尿液報告的原因，在這些數據的變化中，可以發現電解質的攝取及排出是否處在動態平衡之中。

若運動完大量流汗者，可喝運動飲料補充流失的電解質。但平日沒有流汗者，則不需要補充。


## 二、食物和體位法的關聯


吃對食物的練習者，在練習時會身輕如燕，很輕鬆，的確是如此，因為肚子沒有食物的殘留，所以在練習時可以輕易保持吐氣時的縮腹狀態。因此，想要將瑜伽練得好，第一步就是學會吃對食物。

一般來說，早餐可以豐富一些，中餐可以吃少許肉類，但晚餐最好吃輕食、蔬果為主，可喝大量的湯，滿足口腹。晚上儘量不要吃肉類，要吃也吃少量，清蒸或去油處理為佳。

至於要不要全素，看個人需求，但可以選擇健康素，以粗食為主，食物儘量愈天然愈好，烹調的方法愈簡單愈能保持食物的營養。
