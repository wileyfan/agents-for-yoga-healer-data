# agents-for-yoga-healer-data

**瑜伽疗愈原文数据库** — 只存放书籍逐页 Markdown / JSON。不是产品仓。

产品、抽卡 UI、schema、需求请到 [agents-for-healer](https://github.com/wileyfan/agents-for-healer)。

## 本仓放什么

| 路径 | 说明 |
|---|---|
| `judy-yoga/` | 《Judy 瑜伽疗愈》全书逐页 Markdown + ACSM 对齐处方/测试指南 |
| `judy-yoga-therrapy-shoulderandneckpain/` | 《肩颈痛疗愈瑜伽》全书逐页 Markdown |

抽卡 UI 规范的权威源：[`agents-for-healer/disciplines/therapeutic-yoga/docs/inquiry-card-ui/`](https://github.com/wileyfan/agents-for-healer/tree/main/disciplines/therapeutic-yoga/docs/inquiry-card-ui)。本仓不维护 UI 副本。
