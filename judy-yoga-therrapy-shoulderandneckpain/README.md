# 《肩颈痛疗愈瑜伽》疗愈瑜伽智能体高品质知识库

本知识库由原始纸质书籍扫描件高保真转换而成。为了向疗愈瑜伽智能体（Yoga Healing Agent）提供最极致、精准的 RAG（检索增强生成）知识切片召回，我们采用 **Apple Vision 原生高精 OCR 引擎** 进行了段落与版面重构，并使用了 **版面空白分析算法（Vertical Projection Profiling）** 自动裁剪提取了所有关键体式动作局部图，并为每一页生成了细粒度的 Markdown 文件，实现页级精准检索。

## 知识库特色

- **页级细粒度切片**：每页 PDF 对应一个独立的 `.md` 文件，保证智能体检索时 Context 不会发生大跨度偏移，召回内容极其纯净。
- **双层多媒体支持**：包含「全页版式高保真图示」与「裁剪局部体式动作图示」，让智能体不仅能读懂文本，还能结合图片精准对齐姿态。
- **疗愈语义关系描述**：每页都配有精修的「图示与正文关系描述」，帮助智能体深度理解动作要领和骨骼关节受力细节。
